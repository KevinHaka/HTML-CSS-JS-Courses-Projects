# Guess The Number

This project is the final assignment for the Mathesis course **"Introduction to Web Development with HTML5, CSS3, and JavaScript."**

## About the Project

**Guess The Number** is an interactive browser game in which the player has to guess a randomly generated number between 1 and 100. The player has up to ten attempts. After each guess, the game indicates whether the guess is too low or too high and displays the numbers that have already been entered.

The game ends when the player guesses the correct number or uses all ten attempts. Once the game is over, the player can start a new game by selecting the **Restart** button.

My contribution to the project is estimated at approximately **30% of the overall work**, since a substantial part of the template and initial code was provided by the course.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Main Features

- Generates a random number from 1 to 100.
- Accepts guesses through the input field or the **Enter** key.
- Provides feedback after every attempt.
- Keeps a history of previous guesses.
- Allows a maximum of ten attempts per game.
- Displays different messages for correct, incorrect, and completed games.
- Allows the player to restart the game after it ends.
- Uses CSS custom properties to define the interface colors.
